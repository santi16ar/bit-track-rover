# Guía de Contribución

¡Gracias por tu interés en contribuir a Bit-Track-Rover!

Bit-Track-Rover es un carrito robotizado diseñado para transportar objetos dentro de centros de salud. Las contribuciones son bienvenidas en firmware, app móvil, interfaz web, diseño de hardware y documentación.

## Cómo contribuir

1. Hacé un fork del repositorio.
2. Creá una rama nueva para tu cambio:
   ```bash
   git checkout -b feature/nombre-de-tu-funcionalidad
   ```
3. Realizá tus cambios siguiendo el estilo y la estructura del proyecto.
4. Probá tus cambios localmente.
5. Hacé commit con un mensaje claro y descriptivo.
6. Subí tu rama y abrí un Pull Request contra `main`.

## Áreas de contribución

- Firmware: mejoras en control de motores, calibración de sensores, lógica de seguridad.
- App móvil: UI, conexión segura, estado en tiempo real.
- Interfaz web: funcionalidades y usabilidad.
- Hardware: diseño de chasis, gestión de batería, integración de sensores.
- Documentación: manuales, guías, traducciones.

## Lineamientos

- Mantené los cambios enfocados y pequeños cuando sea posible.
- Seguí el estilo de código y las convenciones de nombres existentes.
- Actualizá la documentación cuando cambie el comportamiento.
- Sé respetuoso y constructivo en las discusiones.

## Reportar problemas

Usá el issue tracker para reportar errores o sugerir funcionalidades. Incluí la mayor cantidad de detalles posible: pasos para reproducir, comportamiento esperado vs. actual, entorno y logs si están disponibles.

## Código de Conducta

Todos los colaboradores deben seguir el Código de Conducta del proyecto. Ver `code_of_conduct.md`.
