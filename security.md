# Política de Seguridad

## Versiones compatibles

Las siguientes versiones de Bit-Track-Rover reciben actualizaciones de seguridad:

| Versión | Compatible          |
| ------- | ------------------- |
| 2.0.x   | :white_check_mark:  |
| 1.0.x   | :x:                 |

## Reportar una vulnerabilidad

Si descubrís una vulnerabilidad de seguridad en Bit-Track-Rover, por favor reportala de forma responsable.

1. **No** abras un issue o pull request público para vulnerabilidades de seguridad.
2. Enviá un reporte detallado a los mantenedores por correo electrónico (contacto en el README del proyecto) o abrí una asesoría de seguridad privada en GitHub.
3. Incluí:
   - Una descripción de la vulnerabilidad.
   - Pasos para reproducir el problema.
   - El componente afectado (firmware, app, web, hardware).
   - El impacto potencial.
4. Recibirás una confirmación en un plazo razonable y trabajaremos con vos para entender y resolver el problema.

## Alcance

Esta política aplica al firmware, la app móvil, la interfaz web y cualquier código de soporte del repositorio. Los esquemas de hardware y la seguridad física del dispositivo quedan fuera del alcance de los reportes de código, aunque igual pueden reportarse a modo informativo.

## Divulgación

Te pedimos que nos des un tiempo razonable para abordar la vulnerabilidad antes de divulgarla públicamente. Acreditaremos a los reportantes que sigan este proceso en las notas de lanzamiento, salvo que prefieran permanecer anónimos.
