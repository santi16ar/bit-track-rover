Paso a paso:
1. Instalación

Clonar o descargar el repositorio y descargar web12 y poner la carpeta dentro de htdocs de XAMPP
Abrir http://localhost/phpmyadmin
Crear una base de datos llamada bit_track_bdd
Ir a la pestaña SQL, pegar el contenido de bdd.sql y ejecutar

2. Uso
Abrir en el navegador http://localhost/web12/index.html

Crear una cuenta en opc1.html — se asigna un rover automáticamente según el hospital
Iniciar sesión en index.html
Ver datos personales y rover asignado en homedp.html
