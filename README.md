# bit-track-rover
este es el proyecto que tuvimos en mente y sentimos que podria ayudar significativamente a la industria Argentina. Es un carrito que lleva cosas de un punto "a" a uno "b", busca una ruta, es manejado por medio de una app.
Por ahora solo sigue una ruta por medio de una linea, la app es una posibilidad, que sirva para activar el recorrido.
